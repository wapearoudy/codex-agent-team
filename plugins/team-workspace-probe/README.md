## 0.32.0 初始化证据关联与等待成本

环境初始化链支持显式绑定到当前合同命令：核对原报告完整声明、原生 commandId、工作目录、真实成功退出码和未变输入，保留中断及审查原文。仅支持字面量初始化与 && 链，失败屏蔽、管道、动态命令和不透明脚本仍不能满足验收。旧准备记录缺少预执行指纹时明确提示使用原报告 manifest，不补造历史证明；manifest 全部文件哈希仍核对，输入根按原声明的源码/配置范围选择。

等待增加跨调用 waitCursor 和可直接复用的 continuationArgs，普通进度不触发状态/schema 重读；默认等待55秒，协调调用设置 functions.exec yield_time_ms=60000，减少中途返回的模型往返。阶段交接建议提前至60000当前输入 token 或30次命令，仍只在明确完成边界交接，不强制清空、降档或重跑。插件不能消除宿主有界等待产生的全部空闲模型轮次。

## 0.28.0 执行观察与状态稳定性
