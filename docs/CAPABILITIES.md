# 0.11.1 能力与边界

比较对象的可取能力已经转为插件实现，不宣称全面超过所有产品。主会话仍是 Leader；同一项目一个固定团队，岗位与原生 subagent 一对一。

| 能力 | 已实现 | 验证及边界 |
|---|---|---|
| 岗位生命周期 | 追加岗位、等待/阻塞任务改派、空闲成员移除、持久请求去重 | 活跃成员最多 8；运行中先停止并接收终态，提交/验收后先显式返工；保留原生线程、历史执行者、用量、消息和检查点，不自动迁移 worktree 修改 |
| 质量合同 | 需求/实施/验证/审查/修复/集成阶段，验收条目、写入/排除范围、验证命令、声明目标覆盖 | 可选合同兼容旧团队；成功命令须有本轮宿主记录，模型自述不代替执行；改动路径为成员申报，并非自动文件差异审计或沙箱 |
| 计划确认 | 复杂新团队一次审阅、完整草案编辑、版本/hash 绑定确认、聊天与面板批准、取消；范围扩展暂存 | 初始确认前无初始化/派发；变更不影响原团队；聊天来源由 Leader 记录；明确直接执行可跳过；旧团队普通任务沿用原授权，首次重大变更建立基线并单独确认 |
| 修复与复审 | 稳定问题 ID、独立关闭证据、新修复/复审任务、依赖重定向、轮次上限 | autoRepair 默认关闭；Leader 确认结构化退回才建任务，保留原交付和审查，不自动启动成员或接受结果；严重问题和遗漏目标覆盖阻止最终交付 |
| 面板稳定性 | 有界展示预览、精简状态事件、折叠证据延迟渲染、终态降频 | 400 次大日志浏览器刷新回归；完整数据按需读；已证实沙箱渲染进程崩溃，宿主底层退出原因仍未确认 |
| 执行观察 | 增量读取公开进度、命令输出、文件活动及轮次用量 | 真实原生记录与浏览器回归；依赖宿主持久化，250ms 轮询目标不是端到端承诺 |
| 接续与恢复 | 原成员身份、未完成任务交接、控制能力回执；失联暂停派发 | 自动回归覆盖；不恢复模型、不换成员；完整 Desktop 重启后句柄恢复受宿主控制 |
| 成员通信 | 任务限定的持久消息、稳定请求 ID、原生投递回执、收件确认 | 身份/去重/轮次回归；保存、宿主接收与已读分开，未知投递不重发 |
| 工作流 | 批量预留/绑定、依赖与冲突检查、终态接收建议、独立审查、重试上限 | 有界动作包；Leader 决定并调用原生工具，不运行额外协调模型或自动验收 |
| 用量与上下文 | 宿主轮次 token 归属、未知用量标记、新派发预算、确定性交接压缩 | 不推算订阅账单；缺失数据不是零；无法重置已存在原生线程的累计上下文 |
| 模板与路由 | 保存角色/任务/预算模板，显式模型与推理档位 | 初始化默认不继承完整历史；模型支持由宿主决定，不静默替换固定成员 |
| 工作区隔离 | 可选 Git worktree、责任范围核对、冲突预检、候选暂存合并 | 真实临时 Git 仓库测试；当前项目需干净，候选需提交且独立验收，不自动提交主分支 |
| 搜索与报告 | 任务号/文字/状态过滤、绑定版本的历史分页、公开 Markdown/JSON 导出、耗时记录 | 浏览器与协议回归；缺失时间保持未知，图默认限制 100 张卡片 |
| 长团队历史 | 原始备份、校验分卷、事务写入、旧版写保护、完整业务读取 | 超过旧任务/消息/检查点上限的恢复测试；不能恢复旧版已丢弃事件，仍需磁盘空间 |
| 原生导航 | 成员/任务定位、宿主线程导航请求和回执、面板内精确轮次回看 | 宿主线程工具不支持轮次锚点；自动浏览器测试不等于 Desktop 点击链路验收 |
| 安装与维护 | 官方安装脚本、版本 ZIP/校验和、Windows CI | 来源/安装/驻留连接分别核对；未做公共插件商店审核或 macOS/Linux 全流程验证 |

## 数据与执行边界

只观察已核对父会话、项目和成员标记的线程。公开视图不读隐藏推理，不展示派发输入或账号凭据；报告可能含用户主动输出的项目内容。写范围是职责/调度约束，不是操作系统沙箱。

跨 Leader 转移原生句柄、自动重建宿主协作注册表、原生聊天头部/尾卡槽位与原生轮次锚点缺少宿主公开接口。工具返回明确能力边界及原 Leader 入口，不伪造可控状态。插件不为绕过能力限制建立第二个团队或独立执行器。

0.9.0 数据格式使用 `.v2.json` 与不可变分卷；首次写入旧团队保留精确原文备份，并让旧服务拒绝继续写入。迁移失败、卷缺失、身份或校验和冲突均保留数据并拒绝修改。降级服务不能写入已迁移团队。

0.10.0 首次使用合同、问题台账、自动修复或成员生命周期修改时，保留同一数据文件，设置最低版本与 v2 archive manifest（无分卷时也保留空清单）。0.9.x 读取器会在修改前拒绝该清单；旧团队未使用新能力时继续兼容。升级后重启宿主连接；不能通过删保护字段或降级绕过质量门禁。

0.11.0 新建团队启用计划确认记录和最低版本保护；0.10.0 读取器在修改前拒绝此状态。最近 20 个计划版本原文留存，轮询只携带确认状态摘要。语义上的范围扩展依赖 Leader 正确识别；并非自然语言授权判定器。
