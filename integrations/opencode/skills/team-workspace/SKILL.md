name: team-workspace
description: Coordinate an explicitly requested OpenCode team in the current native Leader session.
---

Keep the current session as Leader. Use the six compact native plugin tools;
read the returned payload once. Router `directory` lists available operations;
`describe` supplies an unknown input schema. Reuse schemas and their hashes.

Use the plugin's verified native project and session identity. Record the user's
team-plan approval before delegation. Execute the returned native `task` packet;
continue its real task_id when requested. Native task uses its configured agent
preset; do not advertise model overrides absent from the host task schema.

To request cancellation use team_workspace_control with action abort and the
real child sessionId. Only an exact direct child in this project is authorized.
The result is a request. Await persisted native message completion or abortion
before plugin settlement. Idle status, final text, or an abort receipt alone does
not prove stopped. Unknown lifecycle stays unknown; never respawn it silently.

Use durable plugin mailbox records when peer steering is unavailable. There is
no second coordinator, Codex session, automatic chat message, or URL dashboard.
